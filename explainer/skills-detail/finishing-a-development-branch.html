2Bốn bước đầu: kiểm tra và hỏi

Chưa có gì bị thay đổi ở bốn bước này. Agent kiểm tra, rồi hỏi bạn.

1

Verify tests

Làm gìChạy test suite đầy đủ của dự án (npm test / cargo test / pytest / go test ./...). Nếu test fail, báo các lỗi và dừng: menu chỉ hiện sau khi suite xanh. Pass thì sang Step 2.

Plan có Test Strategy?Suite xanh chưa đủ: chạy thêm verify-levels --check PLAN_FILE. Nó không chạy gì, chỉ thành công khi cả tám level (format, lint, typecheck, build, unit, integration, e2e, sonar) đã được ghi là PASS hoặc SKIPPED cho đúng HEAD hiện tại, và không file tracked nào đổi sau đó. Kết quả khác thì dừng như suite đỏ. Việc không có plan thì bỏ qua kiểm tra này.

Plan verification not current: <the script's message>
Run verify-levels PLAN_FILE (superpowers:verification-before-completion), then come back.
Tests failing (<N> failures). Must fix before completing:

[Show failures]

3Thực hiện lựa chọn (Step 5)

Chỉ làm đúng lựa chọn bạn đã chọn. Bảng cuối mục tóm tắt hậu quả của từng lựa chọn.

1

Merge local

# Lấy root repo chính để an toàn về thư mục hiện tại
MAIN_ROOT=$(git -C "$(git rev-parse --git-common-dir)/.." rev-parse --show-toplevel)
cd "$MAIN_ROOT"

# Merge trước: xác nhận thành công rồi mới xóa gì
git checkout <base-branch>
git pull
git merge <feature-branch>

# Chạy test trên kết quả đã merge
<test command>

Test fail trên kết quả merge thì dừng, để nguyên worktree và branch rồi điều tra: chưa push gì nên merge chỉ ở local và khôi phục được. Kết quả merge xanh thì dọn worktree (Step 6), rồi xóa branch:

git branch -d <feature-branch>

Discard (chỉ khi bạn yêu cầu)

Cẩn thận

Làm gìCon đường này chỉ tồn tại để đáp lại một yêu cầu rõ ràng là vứt công việc đi. Phải xác nhận trước:

This will permanently delete:
- Branch <name>
- All commits: <commit-list>
- Worktree at <path>

Type 'discard' to confirm.

Chờ đúng xác nhận đó. Khi có, lấy MAIN_ROOT rồi cd ra khỏi worktree, dọn worktree (Step 6) và xóa cưỡng bức branch:

git branch -D <feature-branch>

4Dọn worktree (Step 6)

Chạy cho lựa chọn 1 và discard đã xác nhận. Lựa chọn 2 và 3 luôn giữ worktree. Việc gỡ worktree phải chạy từ ngoài worktree, và dùng các giá trị GIT_DIR, GIT_COMMON, WORKTREE_PATH đã chụp ở Step 2.

6

Quy tắc dọn dẹp

Điều kiệnLàm gì
GIT_DIR == GIT_COMMONRepo thường, không có worktree để dọn. Xong.
WORKTREE_PATH nằm dưới .worktrees/ hoặc worktrees/Superpowers tạo worktree này nên việc dọn là của skill: git worktree remove "$WORKTREE_PATH" rồi git worktree prune (tự chữa: dọn các đăng ký cũ).
Nơi khácMôi trường chủ sở hữu workspace này: để nguyên. Nền tảng có tool thoát workspace thì dùng nó.

Nếu việc gỡ bị từ chốiThông báo contains modified or untracked files nghĩa là worktree chứa file không tồn tại ở đâu khác: plan, ghi chú hay scratch chưa commit. Không bao giờ --force tự ý. Cho bạn thấy cái gì đang nguy hiểm và hỏi:

git -C "$WORKTREE_PATH" status --porcelain -uall

3. Delete them (unrecoverable)

5Những lời bào chữa hay gặp

Bảng Common Rationalizations của skill.

Agent tự nhủThực tế
“Test đã pass lúc nãy trong phiên”Chạy suite trên cây sắp tích hợp. Một lần xanh chỉ chứng minh cho cây mà nó đã chạy.
“Họ rõ ràng muốn merge”Tích hợp là quyết định của bạn. Đưa menu và chờ.
“Họ có vẻ xong tính năng này, tôi gợi ý bỏ nó”Menu đã đầy đủ như viết. Discard chỉ xảy ra khi bạn yêu cầu bằng lời rõ ràng.
“‘Ừ, bỏ đi’ tính là xác nhận”Chỉ từ discard gõ đúng mới cho phép xóa.
“PR lên rồi, worktree là rác”Sửa theo phản hồi PR diễn ra trong worktree đó. Nó ở lại tới khi công việc được merge.
“Worktree khác này có vẻ cũ, dọn luôn”Chỉ dọn worktree dưới .worktrees/ hoặc worktrees/. Mọi thứ khác thuộc về môi trường chủ.
“Gỡ bị từ chối, --force chỉ là hoàn tất việc dọn”Từ chối nghĩa là có file chỉ tồn tại trong worktree đó. --force hủy chúng vĩnh viễn. Cho bạn thấy và hỏi.
“Kết quả merge fail chắc là flaky”Kết quả merge fail dừng mọi thứ. Branch và worktree ở nguyên trong lúc điều tra.
“Base branch hiển nhiên là main”Xác nhận fork point hoặc hỏi. Merge nhầm base rất tốn để gỡ.
“Push bị từ chối, force-push sẽ xong”Push bị từ chối nghĩa là remote đã đổi. Điều tra; chỉ force-push khi bạn yêu cầu rõ ràng.
